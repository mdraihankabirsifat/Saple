Salary insight methodology

Two ranges, two levels of context

Salary aggregation remains a backend and database responsibility. Saple presents the result with clear labels so the source population is easy to understand.

Contribution count matters. A larger number of approved submissions generally provides more context for interpreting a range.

V

Verified Salary Range

Uses only approved salary submissions whose contributor verification is confirmed.

  • verification_status = VERIFIED
  • submission_status = APPROVED
C

Community Salary Range

Uses all approved salary submissions, including both verified and unverified approved contributions.

  • submission_status = APPROVED
