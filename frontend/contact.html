Getting in touch

Saple is maintained by students, so there is no support desk. This page says honestly which route fits which problem.

Saple is an independent BUET CSE academic project for company and career insights. It is not affiliated with, endorsed by, or an official login or careers service for any company named on the site.

Something published looks wrong

Use the Report control on the contribution itself. It is on every public salary, review and interview entry.

Reports go straight to the administrator queue, where each one is triaged and closed with a recorded decision. You are notified of the outcome. This is the fastest route and the only one that creates an auditable record.

A problem with your account

For a forgotten password, use the Forgot password link on the sign-in page.

For a suspended or deactivated account, or to ask for your account to be removed, contact the project administrators through the repository linked on the About page.

You represent a company

Create an ordinary Saple account, then request a company representative assignment from your profile. An administrator reviews the request and either approves it, binding your account to that company, or rejects it with a reason.

Registration alone never grants representative access, and an assignment can be revoked at any time.

A security problem

Please read the Security page first. Report privately, without publishing exploit details, using the contact in /.well-known/security.txt when the owner has configured one.

Coursework and reuse

The project source, schema, migrations and documentation live in the repository linked on the About page. Questions about the design, the ERD or how to run it locally are best raised there, where the answer helps the next reader too.

What Saple cannot help with

Saple cannot pass a message to a company, confirm your employment to a third party, or influence a hiring decision. It is not connected to any employer’s systems.

Vacancies posted here are managed inside this project by representatives whose assignment an administrator approved; Saple does not act as an agent for any company.
